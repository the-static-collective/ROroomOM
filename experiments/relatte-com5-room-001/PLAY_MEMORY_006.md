# Room 006 — The Block Remembers Being Played

Room 006 composes Room Score with the temporal law from Haunted Toaster's Future Rearview Memory Prophecy.

> The Toaster remembers backward, imagines forward, and is forbidden to confuse the two.

ROroomOM adds one extra gate:

> Playback alone is not a verdict.

The first Play Memory slice is receiver-local and receipt-backed.

    addressed particular
       ↓
    resolved Magic Lego
       ↓
    compiled Room Score
       ↓
    CONDUCT
       ↓
    local encounter receipt
       ↓
    explicit human verdict
    KEEP / WEIRD / COMPOST
    + explicit re-open choice
       ↓
    PERFORMANCE MEMORY
       ↓
    derived learning
       ↓
    non-authoritative future invitations

## What is remembered

A memory capsule records only attributable performance facts:

- source particular;
- COM⁵ door;
- local encounter identity;
- SHA-256 of the local encounter receipt;
- Room Score title and clock;
- addressed Lego that actually participated;
- exact resolved SHA-256 identities;
- explicit local human verdict;
- explicit re-open request;
- derived learning references.

It does not copy lyric plaintext into memory.

The same memory can be projected two ways:

    PARTICULAR MEMORY
    sourceSubject → all attributable performances of this particular

    BLOCK MEMORY
    sourceRef → all attributable performances involving this exact addressed Lego

So the song, video, and Text Sheet may each show that they have been played before without pretending that their source objects changed.

## Four permanently separate materials

    RECEIPT  = what happened locally
    VERDICT  = what the human explicitly said about that performance
    LEARNING = bounded derivation from receipt + verdict
    PROPHECY = invitations the next encounter may consider

Laws:

    PLAYBACK != PREFERENCE
    RECEIPT != LEARNING
    LEARNING != PROPHECY
    HUMAN VERDICT != SOURCE AUTHORITY
    MEMORY != SOURCE MUTATION
    PROPHECY != AUTHORITY

## Current prophecy grammar

A memory projection may emit only invitations:

- REOPEN — latest explicit human verdict requested re-entry;
- MUTATE_NEARBY — at least one explicit weird verdict exists;
- COMPOST_RESIDUE — at least one explicit compost verdict exists;
- REPRISE — at least one explicit keep verdict exists;
- CONTRAST — three or more attributable performances exist.

Every invitation has authority = invitation-only.

Nothing automatically reopens, mutates, composts, reprises, contrasts, navigates, renders, or publishes.

## Tamper boundary

The browser-local ledger is not treated as trusted storage. Every memory capsule has a deterministic SHA-256 over its complete semantic core. Before a record contributes to a projection, ROroomOM recomputes that hash. Altered or forged capsules are excluded.

    LOCAL STORAGE != TRUST
    VISIBLE MEMORY != VERIFIED MEMORY
    HASH MATCH != SOURCE AUTHORITY

## Workstation

The Room now includes a PLAY MEMORY shelf. After an actual conducted score, the human can select keep, weird, or compost and separately choose whether to invite a future re-open.

The verified capsule is stored in browser-local storage and survives page re-entry on that browser. The shelf projects memory for the current particular; each addressed Lego card also shows its own verified play count and invitation kinds. The ledger can be exported as JSON.

## Future Rearview composition

This does not import Haunted Toaster's Future Rearview schema or claim Toaster authority. It composes the law:

    PAST FACT
    → explicit human response
    → bounded learning
    → imagined future pressure

with the Room law:

    PROJECTION != AUTHORITY
    DOOR != CROSSING
    LOCAL ENCOUNTER != SOURCE

The resulting object is a local creative memory organ that may influence what the next Room offers without changing what the source was.
