# ROroomOM

The room inside the room: a local-first creative field and opt-in capability-composition experiment.

## Status

Experimental. The first landing preserves a bounded source-inspection bridge and an explicit prepare → human confirm → execute → inspect receipt contract. Descriptors are not authority; no general shell, GitHub write, cross-origin service, or implicit project execution belongs to this Room.

See the upcoming `room-005-capability-crossing` branch for the executable specimen and tests. The main branch is a small entrypoint, not a claim that the whole Static Collective is integrated.
